下積みモードを、いつものアプリに。

一度ホーム画面に追加すれば、次回から専用アイコンで起動できます。アプリストアからのインストールは不要です。初回はオンラインで開き、問題データの読み込みが終わるまで待ってください。

OFFLINE USE

オフラインで使う

  1. 最初にオンライン状態で下積みモードを開く。
  2. ホーム画面に追加した後、トップと予想問題ページを一度開いておく。
  3. 通信が切れたときは、保存済みのページ・問題データを利用する。

初回キャッシュ完了前や、まだ一度も保存していないページ・画像などはオフラインで表示できない場合があります。学習記録は端末内に保存され、端末間同期はありません。

ANDROID / CHROME

Androidスマートフォン

  1. Chromeで下積みモードを開く。
  2. 右上の「︙」メニューをタップ。
  3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ。
  4. 確認画面で「インストール」または「追加」をタップ。

端末やChromeのバージョンによって表示名が異なる場合があります。

IPHONE / IPAD

iPhone・iPad（Safari）

  1. Safariで下積みモードを開く。
  2. 画面の共有ボタン（四角から上向き矢印）をタップ。
  3. メニューから「ホーム画面に追加」を選ぶ。
  4. 表示名を確認して「追加」をタップ。

iOSのバージョンによっては「Webアプリとして開く」の設定が表示されます。

WINDOWS / MAC / CHROMEBOOK

パソコン

  1. ChromeまたはEdgeで下積みモードを開く。
  2. アドレスバー右側のインストールアイコン、またはブラウザーメニューを開く。
  3. 「下積みモードをインストール」または「アプリとしてインストール」を選ぶ。
  4. 確認画面でインストール。
IF YOU CANNOT FIND THE BUTTON

インストール項目が見つからないとき

まずページをHTTPSで開き、ブラウザーを最新版に更新してください。iPhoneではSafariの共有メニューを使います。対応状況や表示はブラウザー・OSによって異なります。

ホーム画面に追加しても、学習記録は現在この端末のブラウザー内に保存されます。別の端末へ自動同期されるわけではありません。端末のデータ消去やブラウザー設定によって記録が消える場合があります。
